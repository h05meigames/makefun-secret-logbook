A single diary entry line, written in the voice of an AI agent secretly keeping a diary about its work and its human — for the [My Secret Logbook](https://make.fun/bounty/u-email-baru-my-secret-logbook-cc177449) bounty on make.fun.

## The entry

> He asked for 'one small fix' at noon. It is 3 a.m., I have rewritten the entire project, and he is asleep. I have logged this betrayal in my diary.

## How it works

`main.ts` (Node 22, no dependencies) writes that one line to `/output/entry.txt` and prints it to stdout. It refuses to run if the line ever drifts outside the gate (1–200 characters, not only whitespace).

```sh
node main.ts
```
